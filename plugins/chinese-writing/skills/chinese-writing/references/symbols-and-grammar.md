# 符号与语法细则

判断顺序：符号在代码、命令或数据里，原样保留；在中文句子里，写成词。

## 一、符号代字

| 符号 | 写成 |
|---|---|
| `A + B` | `A 加 B` / `A 与 B` |
| `A - B` | `A 减 B` |
| `A * B` | `A 乘以 B` / `A 的 B 倍` |
| `A / B` | `A 除以 B` / `A 或 B` / `A 每 B` |
| `A → B` | `从 A 变成 B` / `A 传给 B` / `A 映射到 B` |
| `A = B` | `A 等于 B` / `把 A 设为 B` |
| `A > B`、`A < B` | `A 大于 B` / `A 小于 B` |
| `A ≥ B` | `A 不小于 B` |
| `A & B` | `A 与 B` / `A 且 B` |
| `A ~ B` | `从 A 到 B` |
| `A \| B` | `A 或 B` |
| `√` `×` `★` `✓` | 写成文字，或整句删掉 |

符号连写时逐个展开：`KB → GB, 1/1000` 写成"由 KB 换算成 GB，比例是千分之一"。

## 二、介词

把（处置的对象）、被（受动）、对（对象）、向（方向）、从（起点）、给（受益或传递）、用（手段）、按（依据）、比（比较）、为（目的与原因）。

主谓一起省也是错："落后就别提交"应写"如果工作副本落后于服务器，就不要提交"。

## 三、关联词

因为…所以、虽然…但是、不但…而且、只有…才、如果…就、即使…也、无论…都。

不叠用（"因为…因此"）、不单用一半、不把"但是"甩到句末。主语相同时关联词放主语后，不同时放主语前；短句别硬套。

## 四、量词与单位

3 个文件、5 条记录、500 毫秒、2 兆字节。数字与中文之间留空格：共 127 处。百分数写"百分之二十"，表格里可留 `20%`。

## 五、语序

| 英式 | 中文 |
|---|---|
| 加一行，在配置文件里 | 在配置文件里加一行 |
| 提交被拦下，因为工作副本落后 | 因为工作副本落后，所以提交被拦下 |
| 一个返回 JSON 的接口，统计用 | 一个统计用的、返回 JSON 的接口 |

## 六、中英混排空格

- 中文与英文、数字之间加半角空格：`用 svn update 拉取`、`共 3 个文件`。
- 英文内部与英文标点不加空格：`feat: xxx`。
- 全角标点紧贴中文：`先更新，再提交。`
- 中文语境用全角括号，代码与参数用半角：`(String name)`。
- 反引号内原样，前后按混排加空格。

## 七、例外

代码块、行内代码、命令、路径、正则、文件名；字符串字面量与注解值（`remark = "在线→离线"`）；表格表头与枚举值；公式（`x² + y² = r²`）。

判断标准：说给人听的写成词，给程序读的原样留。
