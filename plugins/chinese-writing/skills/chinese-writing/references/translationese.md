# 翻译腔

中文与英文不是一对一。判断法只有一条：先想汉语里怎么说，写完念一遍，像中国人会说的话吗。

## 词与短语

| 英文 | 别译成 | 译成 |
|---|---|---|
| oh no | 哦不 | 糟了、坏了 |
| I see | 我看见了 | 明白了 |
| make sense | 让它有意义 | 说得通 |
| no way | 没有路 | 不可能 |
| take care | 拿着照顾 | 保重 |
| for your information | 为了你的信息 | 顺带说一句 |
| stub | 桩 | 模拟服务 |
| case | 用例 | 情形、例子、情况 |

语气词与称呼最容易露馅：`dear` 译成"亲爱的"、`hello` 译成"喂"都不像中文对话。

## 句式

| 英文 | 别译成 | 译成 |
|---|---|---|
| a better solution | 一个更好的解决方案 | 更好的方案 |
| in the case of X | 在 X 的情况下 | 如果 X |
| when X happens | 当 X 发生的时候 | X 发生时 |
| it is worth noting that | 值得注意的是 | 直接说那件事 |
| the problem was solved | 问题被解决了 | 问题解决了 |
| we made a decision | 我们做出了一个决定 | 我们决定 |
| conduct an investigation | 进行调查 | 调查 |
| X and Y | X 和 Y（逐字堆） | 顿号、分句或意合 |

三条高发：把"一个"当冠词用、被动句当默认、名词化（"进行…的处理"改成动词）。代词指代不清时重复名词或省略。

## 例外

技术术语与产品名照通行译法或原文（callback 译"回调"，Kubernetes 可写原文）；已有定译不另造（缓存、线程、句柄）；引用原文保持原样。

判断与符号代字同源：说给人听的按汉语写，给程序读的原样留。
