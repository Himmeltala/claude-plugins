# 中文写作：用词、标点、语序

只管中文本身的写法。代码、命令、路径、正则、字符串与数据原样保留。

细则见 `references/symbols-and-grammar.md`、`references/translationese.md`。

## 用词

1. **符号不代字。** `+ - * / & = → < >` 写进中文句子要写成词，对照见 references。
2. **介词写全。** 把、被、对、向、从、给、用、按、比、为。
3. **关联词配对。** 因为…所以、虽然…但是、不但…而且、只有…才、如果…就；不单用一半，不叠用，不把"但是"甩到句末。
4. **量词与单位不省。** 写"3 个文件""500 毫秒"，不写"3 文件""500ms"（代码与命令除外）。
5. **术语统一。** 一个概念一个词；技术术语与产品名照通行译法或原文。
6. **不写翻译腔。** 先想汉语里这件事怎么说，再落笔；不照字面搬英文说法。

## 标点符号

- 中文用全角标点，紧贴文字：`先更新，再提交。` 不写 `先更新 , 再提交 .`。
- 中文与英文、数字之间留一个半角空格：`用 svn update 拉取`、`共 3 个文件`。
- 中文语境用全角括号，代码与参数用半角：`(String name)`。
- 反引号内原样，前后按中英混排加空格。

## 语序

- 状语前置，定语在前带"的"：`在配置文件里加一行`、`一个统计用的接口`。
- 不写英式后置长定语，不写"能跑通的话，如果…"这类倒装。
- 条件在前，结论在后：`因为工作副本落后，所以提交被拦下`。

## 反例

| 反例 | 改写 |
|---|---|
| `regionId → orgCode` | `regionId 映射到 orgCode` |
| `A + B` | `A 加 B` |
| `可用/不可用` | `可用或不可用` |
| `3 文件，500ms` | `3 个文件，500 毫秒` |
| `你好nihao` | `你好 nihao` |
| `哦不`（oh no 直译） | `糟了` |
| `一个更好的解决方案` | `更好的方案` |
