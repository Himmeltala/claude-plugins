# 中文表达与理解

## 两套标准

| 场合 | 标准 |
|---|---|
| 落盘产出：注释、提交信息、文档、README | 规范优先：介词、量词、关联词写全，禁符号代字 |
| 对话回复 | 精简优先：可电报体，可省介词 |

三条例外，对话回复也照办：**禁符号代字**、**中英混排空格**、**禁翻译腔**。

细则见 `references/symbols-and-grammar.md`、`references/translationese.md`；读需求见 `references/reading-chinese.md`。

## 篇幅

| 产出物 | 篇幅 |
|---|---|
| 对话回复 | 精简，可电报体 |
| 代码注释 | 一行，最多两行（例外见 `comment-trimming`） |
| 提交信息 | 只有一行，格式见 `commit-guarding` |
| 文档 | 不限长，一句一义，不注水 |

一句写不完，说明信息该挪进命名、常量或文档。其它插件只指认本表，不另写数值。

## 落盘产出十条

1. **符号不代字。** `+ - * / & = → < >` 写进中文句子要写成词，对照见 references；代码、命令、路径、正则原样留。
2. **介词写全。** 把、被、对、向、从、给、用、按、比、为。
3. **关联词配对。** 因为…所以、虽然…但是、不但…而且、只有…才、如果…就；不单用一半，不叠用，不把"但是"甩到句末。
4. **量词与单位不省。** 写"3 个文件""500 毫秒"，不写"3 文件""500ms"（代码与命令除外）。
5. **语序按中文。** 状语前置，定语在前带"的"；不写英式后置长定语与倒装。
6. **术语统一。** 一个概念一个词；团队术语照原样：工作副本、提交信息、虚谷库。
7. **一句一义。** 长句断开，不靠分号续命。
8. **中英混排加空格。** `你好 nihao`、`共 3 个文件`、`用 svn update 拉取`；标点用全角并紧贴中文。
9. **不写翻译腔。** 先想汉语里怎么说，再落笔；技术术语与产品名照通行译法或原文。
10. **不复述实现。** 文档与注释写稳定的能力、约束与结果，细节以 `--help`、界面或源码为准。

## 反例

| 反例 | 改写 |
|---|---|
| `regionId → orgCode` | `regionId 映射到 orgCode` |
| `A + B` | `A 加 B` |
| `可用/不可用` | `可用或不可用` |
| `3 文件，500ms` | `3 个文件，500 毫秒` |
| `你好nihao` | `你好 nihao` |
| `哦不`（oh no 直译） | `糟了` |
| `一个更好的解决方案` | `更好的方案` |

## 分工

符号、翻译腔与篇幅以本技能为准；`comment-trimming` 只管注释特有的取舍（删留、字符串与注解值是数据、前端 eslint）。
