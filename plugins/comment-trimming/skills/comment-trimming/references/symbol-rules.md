# 前端注释的 eslint 符号规则

本文件记前端 eslint 规则 `illegal-annotation` 对注释符号的实际行为，命中报 error 并可自动修复。

规则扫所有注释，`SYMBOL_RE` 覆盖：ASCII `+`、`×`、箭头区 `←` 到 `⇿`、线条 `─` 到 `╿`、几何图形 `■` 到 `◿`、装饰 `☀` 到 `➿`、emoji。不禁止 `=`、`>`（`=>` 不会被拦）、`-`、`*`、`/`。

Java 与 Mapper XML 没有自动拦截。

两个坑，规则自带的 README 与实现不一致，以源码为准：

- `+` 实际被禁。规则自带测试写着"数学符号不在禁止范围"，与实现矛盾；写 `// CRUD + 标记已读` 会被 `--fix` 静默删掉加号。
- 规则用 `/g` 正则加 `.test()` 遍历注释，`lastIndex` 会残留，导致漏报，别指望它兜全。
