# 注释里的符号禁忌

前端项目由自定义 eslint 规则 `illegal-annotation` 强制，命中报 error 并可自动修复。规则自带的 README 与实现有两处不一致，以下按源码 `SYMBOL_RE` 为准。

禁止范围，只限注释：

- ASCII `+`、`×`
- 箭头区 `←` 到 `⇿`（含 `→`）
- 线条 `─` 到 `╿`
- 几何图形 `■` 到 `◿`
- 装饰 `☀` 到 `➿`（含 `★` `✓` `✗`）
- emoji

Java 与 Mapper XML 同样适用，那里没有自动拦截，写完自己看。SQL 语句、字符串常量、注解值里的符号是数据，不动。

不禁止：`=`、`>`（`=>` 不会被拦）、`-`、`*`、`/`。

两个坑：

- `+` 实际被禁。规则自带测试写着"数学符号不在禁止范围"，与实现矛盾；写 `// CRUD + 标记已读` 会被 `--fix` 静默删掉加号。
- 规则用 `/g` 正则加 `.test()` 遍历注释，`lastIndex` 会残留，导致漏报，别指望它兜全。
