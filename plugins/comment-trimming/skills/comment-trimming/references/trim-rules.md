# 裁剪规则

## 删除

| 类型 | 例子 |
|---|---|
| 装饰横幅与分割线 | `// ===== 用户模块 =====`、`/* ***** */` |
| 注释掉的死代码 | `// private String oldField;` |
| emoji 与无义装饰 | `// TODO 🚀`、`// ★ 重要` |
| 翻译式注释 | `setName()` 上写 `// 设置名称` |
| 复述代码 | `// 循环遍历`、`// 判空` |
| 调用关系与调用链 | `// 由审核服务写入`、`// 被 xxController 调用` |
| 变更履历 | `// modify by lisi`、`// 2023-05-11 张三 新增` |
| 流程标语 | `// 第一步：校验` |
| 简单方法上的 Javadoc | 三行说明一个 `getId()` |
| 无信息量占位 | `/** 构造方法 */` |
| 成段长注释 | 三行以上的括号注、模板注释 |

**横幅先剥装饰，别整行删。** `// ===== 批量一次性查全时段告警 =====` 只去掉 `=====`，留下句子；文字本身是空话（`// ===== 工具方法 =====`）才整行删。

2026-09-23 对 990 个 Java 文件的实测：横幅 127 处、死代码 106 处，值得先扫；日期履历 0 处，不要为它写正则。

## 保留

| 类型 | 例子 |
|---|---|
| 业务规则与口径 | `// 区县级账号无下级区域时回退统计本级` |
| 补偿处理与坑 | `// 虚谷库不支持按聚合表达式排序，须用 SELECT 别名` |
| 单位、精度 | `// 金额单位：万元` |
| 功能性指令 | `//noinspection`、`eslint-disable`、`@SuppressWarnings` |
| 待办 | `TODO`、`FIXME`（去装饰） |
| 接口契约 | `@ApiModelProperty`、`@ApiOperation` |

保留只决定删不删；留下的照样按篇幅标准压短。注释写本段代码自身，不写谁调用、谁消费。

## 压缩

篇幅按 `chinese-writing`。删推导、举例、语气词，留结论与关键字（库名、字段、后果、单位）。

不受篇幅上限限制的三种：类头 Javadoc 与文件头块（整块不动，补充压一句）、功能性指令（按语法原样）、注解值（不算注释，但不摊成段）。

```java
// 改前：两行
/**
 * 登录人下辖的下级区域（省取市、市取区县）；区县无下级区域时返回本级，保证至少带出自身。
 * 登录人无区域或区域码非法时返回空列表，此时不做区域补齐
 */

// 改后：一行
/**
 * 登录人下辖的下级区域（省取市、市取区县），区县无下级时返回本级，无区域或区域码非法时返回空列表
 */
```

压不下去又丢不得：不删，列入报告让用户定。

## 判断

1. 删掉这行，后来人会误改或看不懂吗？会就留；不会就删；拿不准就留。
2. 留的话一行写得完吗？写不完压到一句；压了还超就列入报告。

## 不做

- 不改代码逻辑，只碰注释与空行。
- 不动字符串字面量、注解值、SQL 字符串里的任何字符。
- 注释里的箭头改写成文字，不整行删句；拿不准就留并报告。
- 不整段删长注释，能压就压；压到上限仍丢信息的报给用户。
- 不新写超限注释，不在注释里补背景或举例。
- 不动本次没编辑的文件。
- 不把 `@ApiModelProperty` 当注释删，也不改成 Javadoc。
- 不删功能性指令、`TODO`、`FIXME`。
- 不动 `node_modules/`、`target/`、`dist/`、`build/`。
